Studio

Hack an interactive vis* artifact

vis* includes computer vision and computer-generated visuals, your choice!

Find your interactive vis* artifact

  • (Either) Pick a Processing script
    • (Easiest - should work directly): Examples, Tutorials, Community…
  • (Or) Find a sample that fits your individual pitch idea(s)
    • (Harder - even more complex and you might have to fix it): find an interactive vis* example on GitHub (that fits your individual pitch)!

Install Processing

Your choice (by order of maturity - p5.js highly suggested):

  • Processing.org (Java)
  • p5.js (JavaScript) -> just Start Coding!
  • Python Mode for Processing
  • Processing for Android

Explore examples

  • Examples
  • Tutorials
  • Community…

Modify your chosen artifact creatively

  • Focus on changes that will affect the vis* experience.
  • Make the visual modality more complex.
  • Combine examples if you wish!

Prepare your interactive presentation

  • Create a file named: interactive-presentation-vision.qmd
  • Clarify the provenance (what example(s) you used).
  • Explain your intent, design idea.
  • Describe your creative updates.
  • Overview what you might have done next with more time.
